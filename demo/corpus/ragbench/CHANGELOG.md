# Changelog

## 1.0.0 (2026-11-27)

First stable release.

- BEIR loader (`corpus.jsonl`, `queries.jsonl`, `qrels/<split>.tsv`) and `ragbench download`,
  with a Hugging Face fallback when the UKP mirror is unreachable.
- Metrics: nDCG@10 (linear gains, matching trec_eval `ndcg_cut.10`), Recall@10, Recall@100,
  MRR@10, cross-checked against pytrec_eval in the tests.
- Seeded percentile bootstrap intervals for every mean, and a paired bootstrap for
  comparing two runs on the same queries.
- Retriever protocol: any object with `search(query, k)`, loaded from `module:Name` or
  `file.py:Name`, with optional `index()` and `search_batch()`.
- Built-in retrievers: Lucene-style BM25 (optional Snowball stemming) and a dense
  retriever over fastembed embeddings.
- CLI: `download`, `info`, `run`, `compare`, `report`.
- Benchmark results on SciFact, NFCorpus and ArguAna, generated by
  `scripts/benchmark.sh` and committed unedited under `results/`.
